I recently completed an MSc in Artificial Intelligence and Machine Learning at the University of Birmingham's Dubai campus, after a BE in Electronics and Communication Engineering.

My dissertation asked whether machine learning can predict short-term price direction in Indian equities — and whether more accurate predictions actually make money. I built the full pipeline over **729,383 fifteen-minute bars across ten stocks**: feature engineering, chronological splits to prevent leakage, Random Forest, XGBoost, LSTM and Transformer models, and a cost-aware backtest. Random Forest won on macro F1 (**0.384** against 0.177 for the baseline), but no strategy survived realistic transaction costs. Accuracy and profitability are not the same thing.

I've also worked on medical image segmentation using classical computer vision, and built a Raspberry Pi reading device for blind users that photographs a page and reads it aloud.
